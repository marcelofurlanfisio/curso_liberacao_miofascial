# Curso de Liberação Miofascial

Landing page do curso de Liberação Miofascial do Prof. Marcelo Furlan, com formulário de lista de espera ligado à planilha "Cadastro de interessados - Cursos".

- `index.html` é a página completa
- `fotos/` recebe as fotos indicadas pelos códigos LM-01 a LM-06

Os dados da turma (data, local, valor, condição de pagamento) ficam no bloco CONFIG, no fim do `index.html`.
